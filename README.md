# SUN MEDIA ADMIN

Next.js + TypeScript admin panel, Vercel-first deployment uchun tayyor.

`npm install` so‘ng `npx vercel` bilan loyihani Vercelga ulang. Dashboard → Settings → Environment Variables orqali `.env.example`dagi uch qiymatni Production, Preview va Development muhitlariga qo‘shing. `SUPABASE_SERVICE_ROLE_KEY` faqat server-side qoladi; `NEXT_PUBLIC_` prefiksi berilmaydi.
